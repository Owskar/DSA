# Data Structures and Algorithms

A collection of C++ data structures and algorithms examples, organized by topic.

## Topics

The repository includes practice folders for arrays, hashing, programs, the C++ STL, and sorting.

## Run an example

Compile a standalone C++ source file with a C++ compiler, for example:

```bash
g++ -std=c++17 example.cpp -o example
./example
```

Replace `example.cpp` with the source file you want to run.
